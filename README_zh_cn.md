- ![已完成](https://img.shields.io/badge/%E5%B7%B2%E5%AE%8C%E6%88%90-2ea44f?style=flat-square) 胡狼形态：召唤狼灵集群战斗，将凋零化为自己的力量的领头者
- ![已完成](https://img.shields.io/badge/%E5%B7%B2%E5%AE%8C%E6%88%90-2ea44f?style=flat-square) 蜘蛛形态：使用特制的蛛丝弹与蛛网改造地形迅捷移动，以及困住敌人的织网者

### SP形态

- ![已完成](https://img.shields.io/badge/%E5%B7%B2%E5%AE%8C%E6%88%90-2ea44f?style=flat-square) 悦灵形态：漂浮在空中，只能以紫水晶碎片为食的灵体生物。脆弱但是善于用弓，并可以通过箭矢吸收目标生命值
- ![已完成](https://img.shields.io/badge/%E5%B7%B2%E5%AE%8C%E6%88%90-2ea44f?style=flat-square) 野猫形态：有免疫摔落能力，优势与劣势都比较保守的四足动物
